**OctarineCore** — это pet-проект, реализующий распределённую систему голосового и текстового общения между пользователями. Проект построен по микросервисной архитектуре и разделён на три независимых компонента:

- 🖥 **Клиент (WPF)** — десктоп-приложение для общения.
- 🌐 **API-сервер (ASP.NET Core)** — регистрация, авторизация, чаты, друзья, загрузка медиа.
- 🎧 **Voice Module (UDP + SignalR)** — передача аудиопотока в реальном времени.

---
## 🧠 Архитектура
- WPF-клиент
- │
- ├── REST API → ASP.NET Core → PostgreSQL
- │ │
- │ └── MinIO (хранение аватарок)
- │
- └── SignalR / UDP → Voice Module → UDP-передача между пользователями

## 📦 Быстрый старт (общее представление)

> Подробности по запуску — в README каждого модуля.

1. **API-сервер**
   - Указать строку подключения к PostgreSQL
   - Настроить доступ к MinIO
   - `dotnet run` или сборка через Docker

2. **Voice Module**
   - Запуск сервера SignalR + прослушка UDP
   - Используется динамическая маршрутизация пользователей по RoomId

3. **Клиент (WPF)**
   - Настроить адреса серверов в конфигурации
   - Собрать и запустить из Visual Studio
